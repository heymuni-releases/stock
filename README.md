# heymuni auto 공식 다운로드 (Windows / macOS)

heymuni auto 최신 버전 설치 파일 다운로드 저장소입니다.
최초 1회 다운로드 후 실행하면, 이후 업데이트는 앱 실행 시 자동으로 감지 및 설치됩니다.

---

## 📥 최신 버전 바로 다운로드 (항상 최신 버전 유지)

- **Windows (64-bit 무설치 포터블)**:
  👉 [StockAuto-windows-x64.zip 다운로드](https://github.com/heymuni-releases/stock/releases/latest/download/StockAuto-windows-x64.zip)

- **macOS (Apple Silicon / M1·M2·M3·M4)**:
  👉 [StockAuto-macos-arm64.zip 다운로드](https://github.com/heymuni-releases/stock/releases/latest/download/StockAuto-macos-arm64.zip)

---

## 🚀 실행 방법 안내

### Windows
> ⚠️ **중요 (반드시 압축 풀기 후 실행)**
> 다운로드한 `.zip` 압축 파일 안에서 바로 `StockAuto.exe`를 더블클릭하면 안 됩니다. (임시 실행 모드로 인해 파이썬 라이브러리를 찾을 수 없다는 오류가 발생합니다.)
> 반드시 **마우스 우클릭 → [압축 풀기] (또는 '모두 압축 풀기')**를 완료한 후, 풀린 새 폴더 안에 있는 `StockAuto.exe`를 실행해 주세요.

1. 다운로드한 `StockAuto-windows-x64.zip` 파일에서 마우스 우클릭 후 **[압축 풀기]** (또는 '모두 압축 풀기')를 선택합니다.
2. 압축이 해제된 새 폴더 안으로 들어갑니다.
3. 폴더 안의 `StockAuto.exe`를 실행합니다.

### macOS (최초 1회 실행 시 주의사항)

1. 다운로드한 `StockAuto-macos-arm64.zip`을 더블클릭하여 압축을 해제하고 `StockAuto.app`을 **응용 프로그램(/Applications)** 폴더로 이동합니다.
2. `StockAuto.app`을 실행했을 때 “Apple은 악성 코드가 없음을 확인할 수 없습니다”라는 경고가 나오면 경고 창을 닫습니다.
3. [보안 설정 안내 ZIP 다운로드](https://github.com/heymuni-releases/stock/raw/refs/heads/main/downloads/macos-security-shortcut.zip?v=20261106-2)를 눌러 압축을 풀고, **`보안 설정 열기.html`을 열어 `보안 설정 열기` 버튼을 누릅니다.** 브라우저에서 시스템 설정 앱을 열겠냐고 물으면 **허용** 또는 **열기**를 누릅니다. **개인정보 보호 및 보안** 화면으로 이동합니다.
4. 화면 아래쪽 **보안 → heymuni auto(StockAuto.app) 차단 안내 옆의 그래도 열기(Open Anyway)**를 누릅니다. 요청하면 Mac 로그인 암호 또는 Touch ID로 승인하고, 확인 창에서 **열기**를 누릅니다.

**구버전 앱 ZIP에 들어 있는 `보안 설정 열기.alias`는 원본을 찾지 못하는 오류가 있으므로 사용하지 마세요. 위 안내 ZIP을 새로 받아 HTML 파일을 사용하세요.**

보안 설정 버튼이 동작하지 않으면 **Apple 메뉴 → 시스템 설정 → 개인정보 보호 및 보안**으로 직접 이동하세요. `그래도 열기`가 보이지 않으면 앱 실행을 다시 시도한 뒤 설정을 확인하세요.

현재 앱은 Apple 공증을 받지 않아 최초 다운로드 시 이 확인이 필요할 수 있습니다. macOS 15 이상에서는 우클릭 → `열기`만으로 차단을 해제할 수 없습니다. 바로가기는 설정 화면만 열며, 앱 실행은 사용자가 직접 승인해야 합니다.

자세한 내용은 [Apple 공식 실행 안내](https://support.apple.com/ko-kr/guide/mac-help/mh40617/mac)를 참고하세요.
